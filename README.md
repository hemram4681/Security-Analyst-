## Safety and Ethics

All practical security testing in this repository is intended only for systems, virtual machines,
applications, and networks that I own or have explicit authorization to test.

No external or production system should be scanned, attacked, or monitored without written authorization.

## Evidence

Screenshots, scan outputs, packet captures, and other evidence should be generated from the
authorized local lab environment and added to the relevant task folder.
